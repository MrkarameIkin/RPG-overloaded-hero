ОПИСАНИЕ ПРОГРАММЫ
    Программа RPG overloaded hero - это простенькая игра, в которой Игроку
    предстоит находить различные предметы, каждый из которых имеет свой вес
    и стоимость в золоте. Если игрок сможет унести этот предмет с собой, то
    он заберет его, а сам предмет добавится к нему в инвентарь, но если предмет
    будет слишком тяжелым, то игра выведет, что данный предмет забрать нельзя

ПРИНЦИП РАБОТЫ:
    В самом начале игры, игроку необходимо ввести свое Имя, Класс, Уровень и
    Максимально переносимый им вес
    После создания героя появится Меню с выбором из трех пунтков:
        - Найти предмет - Игрок вводит Название, Вес и Стоимость найденного предмета
        и, если добавленный вес этого предмета не будет превышать максимальный
        вес, который может нести Игрок, то данный предмет добавится в Игроку
        в его инвентарь
        - Статус героя - Выводит Имя Игрока, его Класс, Уровень, Носимый вес, Максимальный
        вес, Общую ценность инвентаря и сам Инвентарь по пунктам, с Весом и
        Стоимостью каждого предмета
        - Выход - Позволяет выйти из игры
